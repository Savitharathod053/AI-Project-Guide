Machine Learning Pipeline & Risk Prediction Engine

Projexa is designed as an educational risk-mitigation tool. Below is an overview of the data engineering, machine learning pipelines, explainability mechanics, and ethical guidelines governing the platform.

1. Machine Learning Classification

The prediction engine utilizes scikit-learn and gradient boosted decision trees. During model selection, multiple classifiers (Logistic Regression, Random Forest, XGBoost) are trained on standardized multi-dimensional feature sets. Models are evaluated using:

  • ROC-AUC Score: Measuring overall discrimination capability across all classification thresholds.
  • High-Risk Recall: Ensuring that struggling projects are identified with minimum false negatives.
  • F1-Score & Accuracy: Balancing precision and recall across successful and at-risk cohorts.

2. Automatic Derived Feature Engineering

Students do not need to manually compute derived metrics. The system calculates:

Metric Formula Significance
completion_ratio completed_tasks / total_tasks Normalized task completion velocity
delay_ratio delayed_tasks / total_tasks Proportion of delayed milestone items
schedule_pressure remaining_tasks / max(1, days_remaining) Work density needed per remaining calendar day
test_coverage_gap max(0, progress% - testing%) Lag in test suite implementation
bug_density bugs / max(1, completed_tasks) Defect concentration in completed code

3. Explainable AI (SHAP / Feature Attribution)

Rather than functioning as a black box, each risk evaluation computes specific feature attributions showing whether variables (e.g. testing coverage, delayed tasks, or schedule pressure) contributed towards increasing or decreasing project risk.

4. Ethical AI & Responsible Guidance

Core Guiding Principle

Projexa never asserts that an academic project is doomed to fail. The platform communicates risk probabilistically, pairing every risk insight with concrete, actionable engineering steps to help students course-correct and achieve project completion.
